# Adventurer Original UI/UX Concept

Open `index.html` locally in a modern browser. This is a standalone click-through concept and does not require a build or backend.

- Seven screens: Basecamp, Field Atlas, Route Brief, Field Mode, Story Studio, Final Review and Trail Settings.
- Routes, metrics and media are illustrative sample content.
- No GPS, routing provider, login, backend, public publishing, SOS or trusted-contact delivery is connected.
- `WORKFLOW.md` documents the flows, guardrails and implementation order.

The screen names, navigation and vector art are an original product direction, not a recreation of a social media platform.
